# Retro — v0.4.0, the gallery home (2026-10-20)

**Scope:** 0.3.0 → 0.4.0. Mockups in an Artifact (4 directions → 4 variations of B → 4
of B1+B2 → final), then the build, with the owner steering live from the TV.

## What went well

- **Mockups before code.** Three rounds of mockups in an hour settled the layout, so
  the build had one target. The owner's live notes during the build ("Ishan" in the
  greeting, the date on its own line) were one-line changes.
- **The catalogue was the source of truth for the card.** The names, years and order
  come from `catalog.json`, so the card shows nothing invented.

## What was hard to understand

- **The playback test proved nothing, twice.** The first "it pauses" came from a
  player that never played. The owner caught it ("it was rendering"). The A/B against
  the old build showed YouTube pauses on Home regardless. So the fix is in, and its
  target app is still unknown.
