# Retro — v0.2.0, the fork and the cars (2026-10-20)

**Scope:** 0.1.0 → 0.2.0. tv-detox forked as `com.rathi.tv.home`, the car screensaver,
installed on the parents' Sony BRAVIA as Home and screensaver.

## What went well

- **The collection was already TV-ready.** The car wallpapers carry their own
  caption, so the dream is pictures plus a clock, with no text layout to get wrong.
- **Screenshots over adb** (`exec-out screencap`) caught the hidden clock on the
  first look, before anyone saw it on the TV.

## What was hard to understand

- **Switching Home on this Sony is not deterministic.** The same command handed Home
  to Google's setup app on one run and to the launcher on the next. Both outcomes are
  written down in ARCHITECTURE.md. The cause isn't known.
